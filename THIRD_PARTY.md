# Third-party soundbanks

The SoundFonts are not in git. `soundbank install` downloads them into the cache and copies the license file next to the bank. `credits` writes `CREDITS.md` for the sources a theme's resolved instruments actually use.

| Bank | Kit | License | Attribution |
| --- | --- | --- | --- |
| GeneralUser GS 2.0.3 | `gm-lite` | GeneralUser GS License v2.0. Bundling and commercial use are allowed. See `licenses/GeneralUser-GS-LICENSE.txt`. | GeneralUser GS by S. Christian Collins |
| MuseScore_General v0.2 SF2 | `gm-full` (default) | MIT. See `licenses/MuseScore_General_License.md`. | MuseScore_General (S. Christian Collins), based on FluidR3Mono / FluidR3 |
| Upright Piano KW (2022-02-21) | `gm-plus` `piano` | CC0-1.0. See `licenses/FreePats-UprightPianoKW-CC0.txt`. | Upright Piano KW by Gonzalo and Roberto for FreePats |
| Spanish classical guitar (2019-06-18) | `gm-plus` `nylon`, `guitar.nylon` | CC0-1.0. See `licenses/FreePats-SpanishClassicalGuitar-CC0.txt`. | Spanish Classical Guitar by Roberto for FreePats |
| YDP Grand (2016-08-04), optional | `gm-plus` `piano.grand` | CC-BY-3.0. See `licenses/FreePats-YDP-Grand-CC-BY-3.0.txt`. | Zenph Studios YDP samples, SF2 by Roberto for FreePats |

The YDP samples are Zenph Studios Yamaha Disklavier Pro recordings made for OLPC by Dr. Mikhail Krishtal and Zenph Studios. The SoundFont and the edits are by Roberto (roberto@zenvoid.org) for the FreePats project. Credit that line when the grand is part of a build. If the file is not installed, `gm-plus` plays MuseScore piano for that name and the credit is not required for that render.

FreePats pages: [piano](https://freepats.zenvoid.org/Piano/acoustic-grand-piano.html), [guitar](https://freepats.zenvoid.org/Guitar/acoustic-guitar.html).
